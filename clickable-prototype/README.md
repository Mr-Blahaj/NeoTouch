# CogniPlay Studio Clickable Prototype

This folder contains a standalone browser-based clickable prototype for the submission.

Open:

```bash
open /Users/rajivkhanna/Downloads/NeoTouch/clickable-prototype/index.html
```

Or serve it from the project root:

```bash
cd /Users/rajivkhanna/Downloads/NeoTouch
python3 -m http.server 8080
```

Then visit:

```text
http://localhost:8080/clickable-prototype/
```
