# TouchWall: Interactive Smart Projector Hand Tracking System

TouchWall is a next-generation computer vision system designed to transform any flat surface (like a wall projected on by a projector) into a smart, interactive touch screen using a standard webcam and advanced hand tracking.

This project uses Google MediaPipe Hands to track finger positions with high accuracy, implements a 4-point perspective calibration system to map camera coordinates to projector screen coordinates, and includes gesture/touch detection to trigger click events on the screen.
